# Python fluency (Java → Python)

1. **Read** `reference.py` one section a day; run it (`python python-fluency/reference.py`). Change a line, predict the result, rerun.
2. **Drill** `drills.py`: replace each `...`, run, aim for 20/20. Target under 3 minutes per drill without looking.
3. **Repeat** from a blank copy after 2 days and 7 days: `git checkout python-fluency/drills.py`, keep your solutions in `drills_mine.py` if you want them.

| Day | Read (reference.py) | Drill (drills.py) |
|---|---|---|
| 1 | 1–4 Java map, numbers, strings, lists | Level 1 |
| 2 | 5–7 dicts, sets, collections | Level 2 |
| 3 | 10 sorting keys, itertools, functools | Level 3 |
| 4 | 8–9 heapq, bisect | Level 4 |
| 5 | 11–13 classes, generators, gotchas | Level 5 |
| 6 | — | Whole file from blank, timed |
