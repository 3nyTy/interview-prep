Reorganize a String with No Equal Neighbors
Given a string containing repeated characters, rearrange all characters so no two adjacent characters are equal. Return any valid arrangement, or an empty string / failure marker when impossible.

Requirements

Input: a string that may contain repeated characters.

Rearrange every character so adjacent characters are always different.

Return any valid arrangement.

If no arrangement exists, return an empty string or an agreed failure marker.

Notes

Clarify whether character comparison is case-sensitive and which failure value the caller expects.

Explain the impossibility condition before coding and preserve every input character exactly once.

Preparation

Implement a construction that always chooses a legal next character while retaining the previous choice until it can safely re-enter consideration.

Test a valid balanced input, a barely feasible dominant character, an impossible dominant character, a one-character string, and mixed case.
