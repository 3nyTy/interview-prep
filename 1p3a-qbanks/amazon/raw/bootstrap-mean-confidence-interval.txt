Requirements

Given a numeric sample, repeatedly draw bootstrap samples with replacement.

Compute the bootstrap distribution of the sample mean and derive a confidence interval from it.

Follow-up: name statistics that bootstrap resampling can estimate well and statistics for which the estimate can be unreliable.

Follow-up: remove the explicit Python for loop using NumPy vectorization.

Notes

The statistical-validity follow-up is intentionally probing. One answer proposed mean and variance as suitable, and median / min / max as unsuitable, but explicitly flagged that boundary as uncertain. Explain assumptions instead of memorizing that list as a rule.

Separate two concerns in the implementation: drawing a matrix of resample indices and reducing each resampled row to one statistic.

Clarify the number of bootstrap draws, confidence level, random seed behavior, and the required interval convention before coding.

Preparation

Implement the scalar-loop and vectorized versions on the same fixed seed and confirm they produce comparable bootstrap distributions.

Rehearse a two-minute explanation of percentile intervals, finite-sample limitations, and why extreme statistics behave differently from smooth averages.
