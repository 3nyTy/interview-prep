Requirements

Each binary-tree node contains one digit. Concatenate the digits along every root-to-leaf path to form a number.

Return the sum of all root-to-leaf numbers.

Follow-up: describe an iterative implementation and the failure mode of recursive traversal on a very deep tree.

Notes

Carry the numeric prefix as traversal state: next = prefix × 10 + node.value. Add it to the total only when the node has no children.

Visit each node once for O(n) time. Recursion uses O(h) call-stack space, while an explicit stack avoids call-stack overflow but can hold O(n) nodes in the worst case.

Preparation

Implement both recursive and iterative depth-first versions and compare their auxiliary-space behavior.

Dry-run a single-node tree, a skewed tree, and a tree containing zero-valued nodes.
