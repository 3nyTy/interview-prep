Requirements

Four problems on CodeSignal in about 70 minutes.

The first two are short array/string warm-ups.

The final two use longer prose contracts, an interface to implement, and hidden tests unlocked by level. Exact problem contracts vary.

Notes

The proctored harness records webcam and screen activity; use external documentation only within the rules shown for the assessment.

Partial credit is awarded by hidden test, so complete and verify early levels before expanding the interface.

Treat this as CodeSignal-format preparation rather than memorization of a fixed problem set.

Preparation

Complete one timed CodeSignal practice session and rehearse its input, test, and level-unlock mechanics.

Implement one in-memory database or banking-style multi-level interface with tests.

Reserve 70 uninterrupted minutes and set checkpoints for moving from warm-ups to the longer back half.
