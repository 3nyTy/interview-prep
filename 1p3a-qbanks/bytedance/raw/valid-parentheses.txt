Requirements

Validate parentheses in a short SRE coding exercise and run the test cases.

Notes

Senior SRE first round ended with a short valid-parentheses coding task that required running all test cases.

For canonical practice, input contains round, square, and curly brackets. Check matching types and nesting. Push opening brackets; each closing bracket must match the stack top. Reject an empty-stack close or mismatched type, and accept only if the stack is empty at the end. Time and worst-case extra space are O(n).

Preparation

Implement the stack check in 15 minutes.

In 10 minutes, test nested and adjacent pairs, crossed nesting, unmatched openings, and a leading closing bracket.
