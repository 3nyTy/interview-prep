Reconstruct Binary Tree from Preorder and Postorder
Reconstruct a binary tree from its preorder and postorder traversals. The prompt aligns with LC 889, but the interview report does not specify uniqueness assumptions or the exact return contract.

Requirements

Given preorder and postorder traversals of the same binary tree, reconstruct and return a tree consistent with both traversals.

Clarify whether node values are distinct and whether the inputs are guaranteed valid.

Clarify whether any valid reconstruction is acceptable when the traversals do not identify a unique tree.

Clarify the expected behavior for empty input and the required node representation.

Notes

The first preorder value is the current root. For a non-leaf subtree, the next preorder value identifies the left-subtree root; its position in postorder determines the left-subtree size. Recurse on the corresponding index ranges for the left and right subtrees.

Precompute value-to-index positions in postorder and pass index boundaries rather than copying slices. With distinct values, this gives O(n) time and O(n) map space plus O(h) recursion depth.

Preorder plus postorder can be ambiguous when a node has only one child. The implementation needs to return one consistent tree, not claim uniqueness unless the prompt guarantees it.

Preparation

Implement the index-range recursion from scratch and write down the left-subtree-size formula before coding.

Trace a full binary tree, a single-node tree, and a one-child chain while checking both generated traversals.

Compare the slice-based and index-based implementations and account for their worst-case time and allocation costs.
