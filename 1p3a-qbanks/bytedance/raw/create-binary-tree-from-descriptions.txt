Requirements

Construct a binary tree from descriptions.

Notes

A roughly twenty-minute coding segment after thirty minutes of resume-based technical questions; detailed input and interface are unspecified.

For canonical practice, each record identifies a parent, child, and left/right flag; values identify unique nodes and the relationships form a valid tree. Return the root. Reuse nodes through a value-to-node map, attach each edge, and record child values. The root is the sole node absent from that child set. For n relationships, expected time and storage are O(n).

Preparation

Implement node reuse and root detection in 20 minutes.

In 10 minutes, test shuffled descriptions, a chain, and parents first encountered as children.
