Requirements

Reverse a linked list in place.

Notes

Ten-minute coding segment following fifty minutes of technical questions. Node interface and return contract are unspecified.

For canonical practice, use a singly linked list and return the new head. The exact interview node interface is unspecified. Maintain previous and current pointers; save the next node before redirecting current.next, then advance both pointers. The processed prefix is reversed while the saved pointer preserves the remaining suffix. Return previous when current becomes null. Time is O(n), with O(1) extra space.

Preparation

Implement iterative reversal in 15 minutes without allocating replacement nodes.

In 10 minutes, trace empty, one-node, and three-node lists; verify identities and reverse twice to recover the original links.
