# 1point3acres Question Banks

Curated interview-question banks scraped from 1point3acres on 2026-09-20 from the logged-in session (AppleScript-driven Chrome).

Scope: the site lists 1227 companies, of which **56 carry curated questions** (1889 in total). All 56 are captured here.

Each company folder contains:

- `questions.json` — structured question records (statement, tags, roles, frequency, last asked, stage)
- `qbank.md` — the same content, readable
- `raw/<slug>.txt` — the captured page, verbatim, including any answer body
