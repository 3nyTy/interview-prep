In-Memory SQL Database with AND Filters
Related Discussion
valon
Problem: In-Memory SQL Database

Implement a simplified in-memory database that supports inserting rows and selecting requested columns. Tables do not need to be created in advance; a table is created automatically on its first insert.

Each row is a key-value map:

Every inserted row contains a unique primary-key column, id.
Other columns may be absent. For example, a row may have email but no name.
Inserting a row with an existing id into the same table replaces the entire old row.
Rows are returned in the order in which their ids were first inserted. Replacing an existing id does not change its position.

Support these operations:

insert: insert or replace a row in a table.
select: retrieve requested columns from a table, optionally with a WHERE clause.
WHERE Clause

A WHERE clause contains simple predicates joined only by AND. There is no OR, parentheses, or other SQL syntax.

Each predicate has one of these forms:

column = 'string literal'
column > integer literal
column < integer literal

= performs string comparison.
> and < perform integer comparison; the corresponding row value is guaranteed to be a valid integer string.
A row is returned only if it satisfies every AND predicate.
If a column used by a predicate is absent from a row, that row does not satisfy the predicate. If a requested output column is absent and no relevant predicate excludes the row, output null for that column.
Input Format

The first line contains an integer Q, the number of operations.

Each of the next Q lines is a JSON object:

Insert:
{"op":"insert","table":"employees","row":{"id":"1","name":"John","email":"abc@gmail.com"}}

Select:
{"op":"select","table":"employees","columns":["name"]}


or:

{"op":"select","table":"employees","columns":["id","name"],"where":"name = 'John' AND id > 5"}

Output Format

For each select, print one JSON array. Each element is an object containing exactly the requested columns; missing columns must be printed as null.

insert operations produce no output.

Constraints
1 <= Q <= 100,000
Each row has at most 20 columns.
Each WHERE clause has at most 20 predicates joined by AND.
Table names, column names, and values contain only letters, digits, and underscores. String literals contain no single quotes.
Example
Input
4
{"op":"insert","table":"employees","row":{"id":"1","name":"John","email":"abc@gmail.com"}}
{"op":"insert","table":"employees","row":{"id":"1","name":"Jessie","email":"qwe@com"}}
{"op":"insert","table":"employees","row":{"id":"2","email":"cde@com"}}
{"op":"select","table":"employees","columns":["name"]}

Output
[{"name":"Jessie"},{"name":null}]
