In-Memory SQL Database: Filter Rows by Column Conditions
Related Discussion
valon
Problem: Build an In-Memory SQL Database (Filtering)

Based on the previous in-memory table, extend querying with a WHERE-like filter.

Functionality
Support filter(condition) to return rows matching the condition (you may combine it with select, e.g., query(select_cols, condition)).
Condition (common simplified version)
A condition is of the form: column_name = value (equality only).
If the column does not exist, return an empty result or raise an error (clarify with the interviewer).
Output
Return all matching rows (either full rows or projected rows, but be explicit).
Constraints
In-memory only.
Preserve insertion order in results.
Example
Columns: ["id","name","city"]
Rows:
{id:1,name:"a",city:"sf"}
{id:2,name:"b",city:"ny"}
Condition: city = "sf"
Output: only the first row
Example
Input
cols: id,name,city
rows: (1,a,sf);(2,b,ny)
query: select name where city=sf
Output
a
